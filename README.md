# דשבורד אינטראקטיבי לדוגמא

אפליקציית ווב פשוטה לבניית דשבורד אינטראקטיבי בעברית, המבוססת על **Dash** ו-**Plotly**. המשתמש בוחר קטגוריה מתפריט נפתח, והמערכת מציגה גרף עמודות וערך מספרי מעודכן בזמן אמת.

## תכונות

- תפריט בחירת קטגוריה (`Dropdown`)
- גרף עמודות דינמי (`dcc.Graph` + Plotly Express)
- הצגת הערך הנבחר בטקסט מתחת לגרף
- ממשק משתמש בעברית

## דרישות מערכת

- Python 3.8 ומעלה
- חבילות Python:
  - `dash`
  - `plotly`
  - `pandas`

## התקנה

1. שכפל או הורד את הפרויקט למחשב שלך.
2. (מומלץ) צור סביבה וירטואלית:

```bash
python -m venv venv
```

3. הפעל את הסביבה:

**Windows (PowerShell):**

```powershell
.\venv\Scripts\Activate.ps1
```

**Windows (CMD):**

```cmd
venv\Scripts\activate.bat
```

4. התקן את התלויות:

```bash
pip install dash plotly pandas
```

## הרצה

מהתיקייה הראשית של הפרויקט:

```bash
python test.py
```

לאחר ההרצה, פתח בדפדפן:

```
http://127.0.0.1:8050/
```

כדי לעצור את השרת, לחץ `Ctrl+C` בטרמינל.

## מבנה הפרויקט

```
.
├── README.md    # תיעוד הפרויקט
```

## איך זה עובד

1. נוצר `DataFrame` של דוגמה עם עמודות `קטגוריה` ו-`ערך`.
2. מוגדר פריסת האפליקציה: כותרת, תפריט בחירה, גרף ואזור טקסט.
3. Callback מקשר בין בחירת הקטגוריה לבין עדכון הגרף והטקסט.
